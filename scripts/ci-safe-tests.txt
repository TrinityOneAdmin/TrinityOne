# THE CI RELEASE-GATE MANIFEST — the safety-critical tests GitHub Actions runs on every push/PR.
#
# WHY THIS FILE EXISTS (and why CI does NOT run the whole suite):
# The full suite (763 files) cannot pass on a bare GitHub runner and was never meant to. ~68 files drive a
# real browser (they run on GitHub's pre-installed Chrome but flake/time out there), some need a phone-style
# IndexedDB the runner lacks, and a couple are KNOWN OPEN UI defects (the 320/360px header overflow). Those
# are verified on the attached PHONES (CLAUDE.md §6), not in CI. Running them in CI only produced a
# permanently-red gate and "Run failed" emails on every push — a gate nobody can read is a gate that guards
# nothing.
#
# So CI runs exactly the SAFETY-CRITICAL, pure-node invariants this gate was created for (see test.yml's
# header): the anonymous read gate / privacy controls, DM sealing, guardian (Shamir) recovery, the finance
# ledger, cross-church isolation, and "the shipped bundle matches its source + the download is what it
# claims". Each file below is pure Node, fast, and deterministic — verified green locally (159 tests, 0 fail,
# 0 skip) before being listed. GREEN here means the arrest-list-grade invariants still hold.
#
# RULES FOR THIS FILE:
#   * One test file per line, path relative to scripts/ (no "scripts/" prefix). '#' starts a comment.
#   * Only add a file that is pure-node (no real browser, no IndexedDB, no attached device) AND passes on a
#     bare runner. If unsure, it does not belong here.
#   * NEVER let this list shrink silently. scripts/ci-manifest-is-honest.test.mjs (itself listed below, so CI
#     runs it) asserts every file here exists, that the core invariants are still present, and that the count
#     has not dropped below a floor. If you remove a line, that guard goes red on purpose — account for it
#     (CLAUDE.md §8).
